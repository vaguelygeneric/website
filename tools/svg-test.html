Opacity

opacity: 1 (full)

Shape at full colour.

opacity: 0.4 on element

The whole element (fill and any stroke) fades. The background shows through.

fill-opacity: 0.4

Only the fill fades. If there were a stroke, it would stay solid. More surgical than opacity.

opacity: 0.4 on a <g>

The whole group fades together as a unit. Inner shapes blend with whatever is behind the group.

Layer order (painter's model — later = on top)

Icon on top of brackets

Icon drawn last, sits on top. Brackets are fully hidden where they overlap.

Brackets on top of icon

Brackets drawn last, cross over the icon. Useful if you want brackets to feel like a frame.

Brackets on top + semi-transparent

Brackets cross the icon but let it show through. The overlap area blends the two colours.

Icon semi-transparent, brackets solid

Icon recedes, brackets pop. The icon blends into the background at overlapping areas.

CSS variables — inline vs hardcoded

var(--accent) — responds to theme

Toggle dark mode. This circle uses the page's --accent variable and follows it.

#3730a3 — hardcoded, static

Toggle dark mode. This stays the same light-mode purple regardless. Wrong for a themed UI.

animateMotion along a path

All examples use the waveform path from your icon. The motion guide path is invisible (fill="none" stroke="none") — it's there purely as a track.

Basic — dot, no rotation

Constant speed (calcMode="paced"). The dot stays upright — fine for a circle, matters for directional shapes.

rotate="auto"

The particle tilts to follow the path tangent. Essential for arrow or teardrop shapes — shows direction of travel.

keySplines easing

calcMode="spline" with cubic bezier curves per segment. This pair gives ease-in-out across the full path — gently accelerates, then decelerates.

Trail effect

Three particles on the same path, staggered with negative begin offsets and decreasing size + opacity. No JS needed.
